# 今夜どこでねる？

1問ずつ答えると、明日の朝の時刻から逆算して今夜の泊まり先を当てる小さなWebアプリ。

- 候補は駅単位。撮影場所（自分の家）・相手の家・そのほかの駅と、駅どうしの電車の時間を入れておく
- 入力は各自の端末（localStorage）にだけ保存する
- 決めた予定は「相手に送る」で `#s=` 付きのリンクにして渡す（`#` の後ろはサーバーに送られない）。設定ごと入るので、同じリンクで相手の画面にも同じ候補が入る
- 朝の結果（守れた／守れなかった）を記録すると、崩れる見込みが実績に寄っていく

ファイルは `index.html`・`style.css`・`app.js` の3つだけ。ビルドなし。
